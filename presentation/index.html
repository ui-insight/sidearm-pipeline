What we don't

No agent has shipped autonomously into a production UI workflow. No long-running loop. No scheduled heartbeat with institutional consequences.

Why

  • OIT throughput. Small apps wait months for institutional review.
  • The data ecosystem. Fragmented, undocumented. Agents would die a slow death in there.

This project is the first formal foray into agentic systems for IIDS. Chosen because it sidesteps both constraints — public data, our own deploy path.

How we work

The repo is the source of truth.

  • AGENTS.md / CLAUDE.md — the agent's onboarding doc and the human's onboarding doc are the same file.
  • docs/adr/ — architecture decisions, dated, sequential.
  • docs/governance/ — data classification before storage, not after.
  • docs/security/ — institutional review checklist, rate-limiting, dependency scanning.
  • mkdocs.yml — every doc in the repo is on the site.
  • .github/workflows/ — CI, security scan, SBOM, e2e tests, docs build, all on every PR.
  • scripts/ — repository maintenance helpers, runnable by humans or agents.
  • ADR-driven — when an opinion is non-obvious, it becomes a tracked decision.

No Confluence page. No Jira board. No status meeting. The deliverable is the diff.

How we work

Markdown is the substrate.

Loop

  1. Issue opened — written in markdown.
  2. Branch named feature/....
  3. Agent reads AGENTS.md, the relevant ADR, the existing module.
  4. Agent proposes a diff.
  5. PR template asks: tests? data classification? security review needed?
  6. Reviewer reads the diff. If it's hard to read, the diff is wrong.
  7. Merge. CI runs. Docs rebuild. Site updates.

Why this works for both humans and agents

The same files that brief the agent brief the new contributor. The same checks that catch a bad PR catch a bad agent run. The repo is the contract.

Process lives in the system, not around it.

How we work

Model-agnostic by design.

The content-generation service uses the Anthropic SDK with a configurable base URL. One environment variable changes the provider.

# Claude
ANTHROPIC_BASE_URL=https://api.anthropic.com

# MindRouter — UI on-prem (Llama, Qwen, Gemma, dots.OCR)
ANTHROPIC_BASE_URL=https://mindrouter.uidaho.edu/v1

# OpenAI — drop-in via the OpenAI-compatible endpoint
OPENAI_API_KEY=...

Same prompts. Same evaluation harness. Same schemas.

Vendors are interchangeable. Prompts and schemas are not. Never bet a project on a single model provider.

How we work

What an agentic sprint actually looks like.

Instructions

AGENTS.md, CLAUDE.md, ADRs. The constraints the agent reads before it writes anything.

Memory

File-based, per-project. What was tried, what worked, what was rejected. Persists across sessions.

Skills

Markdown-defined, composable. SKILL.md / prompt.md per task type. Versioned in the repo, not buried in a vendor's UI.

Heartbeat

Scheduled runs. The agent doesn't only act when called — it checks in, reports drift, opens PRs for cleanup tasks.

The human still owns scope, definition-of-done, review, merge. Orchestration, not abdication.
