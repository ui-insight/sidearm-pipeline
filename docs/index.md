# Vandals Stats Pipeline

Welcome to the documentation for **Vandals Stats Pipeline**.

Vandals Stats Pipeline ingests public Sidearm boxscore data, normalizes it in
PostgreSQL, and prepares that data for internal review, generated coverage, and
athletics website syndication.
