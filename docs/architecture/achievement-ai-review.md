# Achievement AI Prompt and Output Review

Status: **Pending SID human review**

Issue 91 uses AI only after deterministic Achievement Suggestions have been
computed from warehouse facts. The model may reorder verified candidates and
select one server-generated phrase variant per candidate. It cannot create
candidates, write new factual claims, calculate facts, or change numbers.

## Versioned prompt contract

Prompt version: `achievement-ranking-v1`

The system prompt tells the model to:

- use every supplied `suggestion_key` exactly once
- treat supplied facts as immutable
- return one of the supplied `allowed_phrasings` exactly
- use only supplied numerals and preserve the player, metric, and Coverage
  Window qualifier
- avoid converting partial history into an all-time or program record
- return only a JSON object with a `ranked_suggestions` array

Each model input includes only a source-backed, pending suggestion whose
Coverage Window is `complete` or `partial`. It includes the stable suggestion
key, player and metric labels, achievement type, deterministic notability score,
immutable phrase facts, and fact-only allowed phrase variants generated by the
server. Raw source content and URLs are not sent.

The strict output shape is:

```json
{
  "ranked_suggestions": [
    {
      "suggestion_key": "an existing key",
      "phrasing": "one concise sentence"
    }
  ]
}
```

Extra fields, missing or duplicate keys, any phrase outside the supplied
fact-only variants, new numerals, number words, omitted evidence numerals,
changed player or metric labels, omitted coverage qualifiers, and unsupported
record claims reject the entire response. Nothing is persisted until every item
passes validation.

## Representative output for review

Given the partial Coverage Window in the automated review fixture, these are
representative accepted sentences:

1. `Alice Adams reached 100 career Points since 2023-24, for a verified total of 110.`
2. `Alice Adams recorded 50 Points, ranking No. 2 since 2023-24.`
3. `Alice Adams set a career high with 50 Points since 2023-24.`
4. `Alice Adams set a 2025-26 season high with 50 Points since 2023-24.`

The model may change this ordering, but it must return all four candidates and
each phrase must pass the deterministic guards.

## Operational behavior

Ranking is invoked manually with
`POST /api/v1/achievement-suggestions/games/{game_id}/rank`. Deterministic
suggestions remain available through the corresponding `GET` endpoint when the
model or credentials are unavailable. Validated phrasing and ordering are saved
with the model name, prompt version, SHA-256 phrase hash, and ranking timestamp.
This AI output remains a suggestion; the later Verdict workflow controls
approval or rejection.

## SID verdict workflow

The authenticated `/achievements` workspace shows only ranked suggestions with
validated phrasing. Suggestions are grouped by game and retain their AI order,
warehouse fact, source snapshot, and Coverage Window qualification. The queue
supports three durable states: `pending`, `approved`, and `rejected`.

- `GET /api/v1/achievement-suggestions/review-queue` returns a paged game queue
  for one state and counts for all three states.
- `PATCH /api/v1/achievement-suggestions/{suggestion_id}/verdict` records an
  `approved` or `rejected` verdict with the authenticated reviewer and time.
- Re-ingesting the same game preserves AI phrasing and SID verdicts only while
  the verified fact and Coverage Window remain unchanged. Changed facts return
  to pending and require fresh ranking and review.
- The Record Book and source snapshot remain directly accessible from review.

Verdicts tune only notability, never facts. For each metric and achievement
type, later detection runs apply the prior approval rate with two virtual
approvals: `(approved + 2) / (approved + rejected + 2)`. This starts at `1.0`,
never boosts a pattern, and progressively down-weights patterns rejected by the
SID. The base score, multiplier, and prior counts are retained in suggestion
context for explanation and testing.
